# 学习路线

每个阶段建议一次学习会话。先回答问题，再做实验，最后记录证据。以下验收标准是本项目的练习设计。

| 阶段 | 输出 | 验收标准 |
| --- | --- | --- |
| 01 定位 | 数据流图 | 标出用户输入、模型输出、工具结果、下一次请求 |
| 02 CLI | 同一任务的 text / JSON 对照 | 找到最终答案与过程事件的位置 |
| 03 扩展 | `/learn 03` 与工具搜索结果 | 解释注册与激活的区别 |
| 04 Codemode | 标题摘要与大小对比 | 三次调用全部完成；说明单次失败如何处理 |
| 05 MCP | 自选服务的连接记录 | 找到一个真实工具，记录 schema 与 exposure |
| 06 虚拟模型 | 路由决策表 | 覆盖用户请求、continuation、retry；模型不可用时有处理策略 |
| 07 上下文 | 会话片段与缓存用量对照 | 区分观察到的效果与自己的推测 |
| 08 Durable | 停机与恢复报告 | 在自己的实验中证明哪些状态被恢复、哪些操作被重新执行 |

目录可通过 `npm run lessons` 查看；单课用 `npm run lessons -- 08`。

每阶段完成后用 [日志模板](05-journal.md) 保存自己的理解。进阶任务先设计后实现，不把未运行的实验标记为完成。
