Pi 将自己定位为最小、可扩展的 agent harness。1.0 的新增能力包括 Codemode 与原生 MCP、非聊天模型调用、虚拟模型、延迟工具加载、Anthropic 缓存预热、会话中途的系统消息，以及新的主题和默认全屏界面。

Pi Durable 是另一个实验性包，面向长时间运行的 agent 应用。文章强调保持核心简洁，同时允许构建者塑造工作流。

## 本项目的学习问题

下面是自己的练习设计：

- 给一个课程工具增加 `deferred` exposure，观察模型怎样发现它。
- 让脚本组合三次工具调用，比较原始信息与过滤摘要。
- 设计两种模型的路由策略，为失败重试写出规则。
- 给一个任务设计进程重启实验，区分“有聊天历史”和“可恢复执行”。

功能名称不是效果保证。缓存收益、路由质量和恢复行为都需要实验记录支撑。
